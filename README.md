# Ulan's Birthday Invitation

GitHub Pages-ке дайын статикалық сайт.

## 7 фотоны қалай ауыстыруға болады
`images` папкасының ішіне өз суреттеріңді салып, мына атаулармен атаңыз:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `photo6.jpg`
- `photo7.jpg`

Фотолардың **разрешениесі немесе бағыты (тік/көлденең) әртүрлі болса да**, сайт оларды галерея өлшеміне автоматты түрде бейімдейді. Көрініс бұзылмауы үшін `object-fit: cover` қолданылады — яғни қажет болса суреттің шеттері аздап қиылады, бірақ фото созылып кетпейді.

JPG, PNG немесе WebP қолдануға болады. Егер файл атауын өзгертсеңіз, `index.html` ішіндегі сәйкес `src` атауын да өзгертіңіз.

## Негізгі файлдар
- `index.html` — негізгі бет
- `style.css` — дизайн
- `script.js` — countdown, particles, RSVP, lightbox, музыка
- `images/photo1.jpg` ... `images/photo7.jpg` — 7 фото
- `music.mp3` — музыка
