# Ulan's Birthday Invitation

GitHub Pages-ке дайын статикалық сайт.

## Файлдар
- `index.html` — негізгі бет
- `style.css` — дизайн
- `script.js` — countdown, particles, RSVP, lightbox, музыка
- `images/photo1.jpg` ... `photo4.jpg` — кейін өз суреттеріңізбен ауыстырыңыз
- `music.mp3` — кейін өз музыкаңызбен ауыстырыңыз

## Өзгерту
`index.html` ішінен аты-жөнін, датаны, мекенжайды және мәтіндерді өзгертуге болады.
`script.js` ішіндегі `EVENT_DATE` countdown датасын басқарады.

## GitHub Pages
1. GitHub → New repository.
2. Мысалы, `ulan-birthday` деп атаңыз.
3. Repository-ді Public етіңіз.
4. ZIP-тен шыққан файлдарды repository-дің ең жоғарғы деңгейіне жүктеңіз.
5. `index.html` міндетті түрде repository-дің түбірінде тұрсын.
6. Settings → Pages → Source: `Deploy from a branch`.
7. Branch: `main`, Folder: `/ (root)` → Save.
8. Бірнеше минуттан кейін GitHub Pages сілтемесін аша аласыз.
